# House selector textures

The 1K PBR texture maps in this directory are sourced from
[Poly Haven](https://polyhaven.com/) and released under
[CC0](https://polyhaven.com/license).

- `grey_roof_tiles-*`: [Grey Roof Tiles](https://polyhaven.com/a/grey_roof_tiles)
- `white_bricks-*`: [White Bricks](https://polyhaven.com/a/white_bricks)
- `wooden_planks-*`: [Wooden Planks](https://polyhaven.com/a/wooden_planks)
- `concrete_floor-*`: [Concrete Floor](https://polyhaven.com/a/concrete_floor)
- `leafy_grass-*`: [Leafy Grass](https://polyhaven.com/a/leafy_grass)
- `dirt-*`: [Dirt](https://polyhaven.com/a/dirt)
- `gravel_road-*`: [Gravel Road](https://polyhaven.com/a/gravel_road)

Each material includes diffuse, OpenGL normal, and roughness maps.

The `mobile/` directory contains 512×512 WebP variants used below the
`md` breakpoint. They preserve the same material maps while reducing the
initial mobile texture transfer from about 14.8 MB to about 0.62 MB.
