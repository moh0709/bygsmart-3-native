Hvad "Rich" tilføjer (alt via eksisterende tokens — intet bibliotek ændres):
• Bløde overflade-gradienter på kort (surface → canvas) + indre top-highlight for dybde
• Brand/status-farvede skygger på ikon-bobler og knapper (giver "løft" og materialefølelse)
• Gradient-fyld i ikon-bobler og fremhævede knapper (135° lys→mørk)
• Signatur-kort (projekt-hero, AI) bliver fuldfarve-gradient-flader med glas-knapper og lys-glød
• Gradient + drop-shadow på progress-ringe
Bevaret 100%: layout, spacing, sizing, komponent-struktur, dark mode, a11y, tokens.
